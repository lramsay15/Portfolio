Projects available in the repository:

Inventory: stock-taking and managing tool. Allows user to capture data on an item of stock, view stock on hand, re-stock inventory, search for inventory given the product code and so on.

Task manager: allows for management of tasks and the users they are assigned to. Allows for the adding of tasks, viewing and updating the user's tasks, a statistical overview of the tasks on file, and, for admin users, adding new users, deleting tasks from the file, and viewing completed tasks.

Shelf tracker: exercise in applying SQL lite. Handles data for a bookstore by storing book and author details in relational databases, and provides an interface to enter books and authors, update details, search by ID code, view details on the database, and delete books from the database.
